什么是二维码生成器？

二维码生成器是一款可以将网址、Wi-Fi 信息、简短消息等任意文本立即转换为二维码的工具。无论是名片、菜单、海报还是演示文稿都需要二维码时，无需安装任何软件即可立即生成。生成的二维码可免费下载为 PNG 或 SVG 文件，所有处理均在浏览器中即时完成。

使用方法

首先选择您需要的二维码类型（网址、文本、Wi-Fi、联系人、邮件、电话、短信、日程或位置），然后填写相应字段，输入的同时下方会立即显示二维码预览。满意后点击「PNG」或「SVG」按钮即可下载文件。如果输入内容过长无法生成二维码，页面会显示提示信息。

适用场景

  • 快速分享 Wi-Fi 密码或网站地址
  • 在名片或宣传单上添加二维码
  • 将印刷菜单链接到在线点餐页面
  • 在演示文稿或海报中嵌入二维码

二维码类型的区别与打印注意事项

二维码扫描后的行为取决于其数据类型。网址型二维码扫描后会立即打开网站，Wi-Fi型无需输入密码即可自动连接到网络，名片型（vCard）会将联系人信息直接保存到扫描者的通讯录应用中。选择符合用途的类型，才能让用户扫描后立即获得预期的结果。

打印使用时的检查清单

  • 留出至少为二维码模块尺寸4倍的空白区域（安静区）— 空白不足会导致扫描器无法识别二维码边界
  • 前景色与背景色要有足够的明度对比 — 对比度不足会大幅降低识别率
  • 打印尺寸至少为扫描距离的1/10 — 例如在1米距离扫描，建议打印尺寸至少10厘米
  • 添加logo时请将纠错级别设为较高（H），这样即使logo遮挡了部分区域也能正常还原

常见问题

可以免费使用吗？
可以，无需注册即可免费生成并下载二维码。
可以下载哪些格式？
支持PNG和SVG两种格式。PNG适合直接用于文档和打印，SVG是放大也不会失真的矢量格式。
输入的字数有限制吗？
由于二维码本身的容量限制，内容过长可能无法生成。若内容过长，页面会显示提示信息，建议使用较短的网址或精简文本。
可以制作Wi-Fi或名片二维码吗？
可以。在顶部分类中选择Wi-Fi、联系人、邮件、电话、短信、日程或位置，即可生成对应用途的二维码。例如Wi-Fi二维码在扫描后会自动连接到该网络。
二维码有有效期吗？
本工具生成的二维码本身没有有效期。但网址型二维码如果链接的网页被删除或地址变更，将无法继续使用。
二维码无法扫描时该怎么办？
通常是打印尺寸过小、空白不足或logo过大导致的。请尝试提高纠错级别并留出更多空白后重新生成。
生成的二维码信息会保存到服务器吗？
不会。二维码在浏览器中即时生成，您输入的网址或文本不会被发送或存储到服务器。

本工具的二维码生成过程完全在您的浏览器本地完成，您输入的内容不会被发送或存储到服务器。
