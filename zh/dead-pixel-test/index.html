什么是坏点测试?

坏点测试是在显示器、笔记本电脑、电视屏幕上全屏显示红、绿、蓝、白、黑等纯色,让你用肉眼扫视整个屏幕,找出坏点(始终亮着或熄灭的像素)、残影和背光不均的工具。在纯白或纯黑画面上,亮点或暗点会格外明显;在原色(红、绿、蓝)画面上,则更容易发现只有某一种颜色显示不出来的子像素故障。无论是刚拆封的新显示器,还是购买二手显示器前的现场检查,几分钟内就能完成确认。

使用方法

点击任意颜色按钮即可立即进入全屏模式。点击屏幕或按 → 键切换到下一个颜色,按 ← 键切换到上一个颜色,按空格键可开始或停止自动连续播放。如果想不用动手就按顺序切换,请点击「开始自动播放」按钮 —— 在按钮内的数字框中输入想要的切换间隔(秒,默认3秒)后点击按钮,就会立即按该间隔开始自动播放。检查完毕后,按ESC键或屏幕右上角的退出按钮即可退出。

适用场景

  • 拆封新购买的显示器,在可退货期限内确认是否存在坏点时
  • 购买二手显示器前,在卖家面前现场快速检测时
  • 怀疑屏幕上出现的斑点或残影是否为真正的面板故障时
  • 想检查笔记本电脑、电视等其他显示设备的画质时

为什么坏点在不同颜色下看起来不一样?

液晶屏幕的每个像素都由红、绿、蓝三个子像素组成,因此只要有一个子像素故障,该像素往往就无法显示某一种特定颜色。例如,只有红色子像素故障时,该像素在白色画面上会呈现淡青色,在纯绿色或纯蓝色画面上几乎看不出异常,却唯独在纯红色画面上显得发黑、格外醒目。因此,只检查一种颜色是不够的,必须按顺序检查三原色加上白色和黑色,才能不遗漏任何坏点。

检测时值得了解的知识

  • 坏点(dead pixel,始终熄灭)和亮点(stuck pixel,始终点亮)的成因不同 —— 亮点偶尔可通过闪烁图案恢复,但坏点大多是物理故障,无法通过软件修复
  • 调暗屏幕检测时更容易发现亮点(stuck pixel),调亮屏幕检测时更容易发现暗点(dead pixel)
  • 不同显示器厂商和销售商对「正常」的判定标准(可接受的坏点数量)各不相同,退换货前最好先确认该商家的政策
  • 如果屏幕出现斑驳的亮度不均,那可能不是坏点,而是背光不均匀(均匀度)问题 —— 在灰阶图案下会格外明显

常见问题

使用闪烁图案真的能修复坏点吗?
有报告称快速切换颜色能让残留像素(亮点)恢复正常,但这种效果并未得到验证或保证。完全熄灭无法点亮的真正坏点,无法用这种方法修复。
浏览器不支持全屏也能使用吗?
可以。即使浏览器阻止了全屏切换,测试画面本身也会不留滚动条和边距地填满整个视口(100%),因此不影响检测。
这个工具会将屏幕内容发送或记录到服务器吗?
不会。颜色切换和画面显示全部只在浏览器内处理,不存在任何发送或保存到服务器的信息。
可以在手机上使用吗?
可以,在智能手机或平板电脑上同样可以进行相同的纯色全屏测试。

本工具的所有画面切换均只在浏览器内处理,没有任何数据会被发送或保存到服务器。
